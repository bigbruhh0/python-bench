# Pneumatic Clamp Simulator

Программа симулирует зажатие и разжатие пневмоцилиндра. Динамическая панель PyQt5 показывает входы, выходы, состояние автомата, оставшееся время операции и журнал событий. Реального оборудования в проекте нет.

## Стек

- Python 3.10+.
- PyQt5 — графический интерфейс.
- SQLite из стандартной библиотеки — хранение настроек и кодов ошибок.
- pytest — модульные тесты.

## Структура проекта

- `bench_sim/__main__.py` — точка запуска, собирающая слои приложения.
- `bench_sim/hal.py` — контракт HAL и его реализация `MemoryHAL`.
- `bench_sim/logic/controller.py` — конечный автомат и логика таймаутов.
- `bench_sim/data/settings.py` — SQLite-репозиторий и проверка настроек.
- `bench_sim/ui/gui.py` — графическая панель симулятора.
- `bench_sim/ui/cli.py` — альтернативный консольный интерфейс.
- `tests/` — тесты состояний, выходов, таймаутов, настроек и интерфейса.

## Обоснование решений

`MemoryHAL` заменяет LinuxCNC, чтобы запускать и проверять логику без станка и оборудования. Контроллер зависит от общего интерфейса HAL, поэтому имитацию можно заменить адаптером к реальному HAL. Для таймаутов используются монотонные часы: перевод системного времени не влияет на работу, а в тестах время можно продвигать без ожидания.

## Установка и запуск на Windows

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
python -m bench_sim
```

По умолчанию запускается графический интерфейс. Для консольного режима используйте `python -m bench_sim --cli`.

## Возможности и ограничения

На панели можно запускать зажатие и разжатие, вручную переключать датчики, настраивать таймауты и включать или отключать автоматическое подтверждение. Настройки сохраняются в SQLite. При первом запуске создаются `settings.sqlite3` и `bench.log`; журнал содержит переходы состояний и ошибки. Кнопка «Посмотреть полные логи» открывает журнал, в том числе записи предыдущих запусков, а кнопка «Обновить» перечитывает файл.

По умолчанию `T_clamp = 5` секунд, `T_unclamp = 2` секунды. Автоподтверждение включено: датчик зажатия срабатывает через 1 секунду, разжатия — через 0,5 секунды. Если подтверждение не поступило до истечения таймаута, операция завершается ошибкой.

Консольные команды:

- `clamp` / `unclamp` — запустить зажатие или разжатие.
- `sensor clamped on|off` / `sensor unclamped on|off` — вручную изменить состояние датчика.
- `wait SECONDS` — подождать и проверить таймаут.
- `status` — показать состояние, выходы и код ошибки.
- `reset` — сбросить ошибку после устранения конфликта датчиков.
- `help` / `quit` — показать справку / выйти.

Переход считается успешным, когда включается соответствующий датчик. При таймауте контроллер выключает оба выхода и выставляет `E001` или `E002`. Одновременные команды или срабатывание двух датчиков дают `E003`; ошибка остаётся до ручного сброса.

## Тесты

```powershell
pytest
```

Часы контроллера передаются как зависимость, поэтому тесты проверяют таймауты без реального ожидания.
